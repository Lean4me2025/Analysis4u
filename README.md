# Analysis4U Landing Page

This repository contains the landing page for **Analysis4U.net**, offering
Business, Process, and Data Analysis services.

The site includes:

- Hero section with blue digitized background
- Clear problem statement ("No dashboards, No metrics...")
- Service overview
- About section (Drew Harris)
- Contact form integration via GoDaddy

## File Structure
- `index.html` — Main landing page
- `style.css` — Page styling
- `assets/images/` — Background and other visuals

## Deployment
This page can be deployed on:
- GoDaddy Website Builder (main site)
- Vercel (optional alternative)
- Netlify (optional)

Current live domain: **https://analysis4u.net**
